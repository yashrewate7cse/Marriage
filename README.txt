THE RUBY HOUR — Wedding Invitation Demo

Files:
- index.html
- style.css
- script.js
- assets/feeling-good.mp3

Open index.html through a local web server or publish the folder as a static website.
Keep the assets folder beside index.html.

Music behaviour:
- Feeling Good starts at 100% HTML audio-player volume for the first complete play-through.
- At the first loop boundary, the player volume changes to 70%.
- Every following repeat remains at 70%.
- There is intentionally no mute, pause, or sound-control button anywhere on the page.
- The music element is global to the page, so it continues while visitors scroll through sections.
- Mobile browsers may block audible autoplay until the visitor interacts with the page. The site retries on the first ordinary touch/scroll/key interaction; no separate music button or tap-to-open gate is shown.

The opening glitter animation automatically reveals the invitation and velvet-curtain hero. The invitation content is a visual demo; replace the sample couple, venue, date, and RSVP details before real use. RSVP currently displays a local demo confirmation and is not connected to a backend/database. Remote Google Fonts, venue images, and map embed require internet access.
